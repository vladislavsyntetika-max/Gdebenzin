# АЗС СПб — бот-мониторинг топлива

Telegram-бот, где водители сами отмечают, есть ли топливо на конкретной АЗС.
Данные общие: то, что отметил один человек, видят все остальные.

Файлы:
- `bot.py` — весь код бота (один файл, чтобы было проще разбираться и редактировать)
- `webserver.py` — веб-сервер карты (Mini App), работает в том же процессе, что и бот
- `webapp/map.html` — страница с картой, открывается внутри Telegram по кнопке «🗺 Открыть карту»
- `requirements.txt` — зависимости
- `amvera.yml` — конфиг для хостинга Amvera
- `.env.example` — образец файла с токеном для локального теста

---

## Шаг 1. Получить токен бота

1. В Telegram найдите `@BotFather`.
2. Отправьте `/newbot`.
3. Придумайте имя (например "АЗС СПб — топливо") и username, обязательно заканчивающийся на `bot` (например `azs_spb_fuel_bot`).
4. BotFather пришлёт токен вида `123456789:AAExampleTokenNotReal`. Скопируйте его — он больше нигде не появится в таком виде, но его всегда можно перевыпустить через `/token` у BotFather.

## Шаг 2. Проверить бота у себя на компьютере (необязательно, но полезно)

Нужен установленный Python 3.10+.

```bash
cd azs-bot
python -m venv venv
source venv/bin/activate        # на Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env` и вставьте токен:
```
BOT_TOKEN=ваш_токен_от_botfather
DB_PATH=data/db.sqlite3
```

Запуск:
```bash
python bot.py
```

Напишите своему боту в Telegram `/start` — должно появиться меню сетей АЗС. Если работает — переходим к деплою. Остановить локальный запуск: `Ctrl+C`.

## Шаг 3. Разместить бота на Amvera (чтобы он работал 24/7 без вашего компьютера)

Amvera — российский облачный хостинг, разворачивается через `git push`, есть стартовый бесплатный баланс для теста, работает с российскими картами.

1. Зарегистрируйтесь на **amvera.ru** (кнопка "Регистрация" на сайте, либо `cloud.amvera.ru`).
2. В личном кабинете: **Приложения → Создать приложение**. Укажите название проекта (например `azs-spb-bot`) и выберите начальный тариф.
3. На экране загрузки кода выберите **Git**. Amvera покажет команду вида:
   ```
   git remote add amvera https://git.amvera.ru/ваш_логин/azs-spb-bot
   ```
4. В папке проекта на своём компьютере:
   ```bash
   cd azs-bot
   git init
   git add .
   git commit -m "Первый коммит"
   git remote add amvera https://git.amvera.ru/ваш_логин/azs-spb-bot
   git push amvera master
   ```
   Git попросит логин/пароль — используйте те, что указали при регистрации в Amvera.
5. Файл `amvera.yml` уже в проекте, дополнительно ничего генерировать не нужно — Amvera прочитает его и поймёт, что это Python-приложение, запускаемое командой `python3 bot.py`.
6. **Важно.** Зайдите в настройки проекта → **Переменные окружения** и добавьте:
   - `BOT_TOKEN` = ваш токен от BotFather
   - `DB_PATH` = `/data/db.sqlite3`
   - `ADMIN_ID` = ваш числовой Telegram ID (узнать его можно у бота @userinfobot — напишите ему `/start`, он пришлёт ваш id). Без этой переменной сообщения о неточностях от пользователей будут сохраняться в базу, но не будут вам приходить в личку.
   - `CHANNEL_ID` = юзернейм канала проекта (например `@gdebenzin_spb`) или его числовой id — куда бот сам публикует топ недели каждый понедельник в 09:00 МСК. Необязательная переменная: если её не задать, бот просто не публикует ничего сам (можно постить топ вручную через `weekly_report.py`, см. ниже). **Бот должен быть администратором канала**, иначе публикация не пройдёт.

   Второе обязательно: без этого база данных будет писаться в папку сборки, которая стирается при каждом обновлении кода, и все отчёты о топливе будут пропадать. Путь `/data` — это папка постоянного хранилища Amvera, она переживает обновления.
7. Дождитесь статусов "Выполняется сборка" → "Выполняется развёртывание" → "Приложение запущено" (обычно 2–4 минуты).
8. Напишите боту `/start` в Telegram — теперь он работает без вашего компьютера.

### Обновление кода в будущем

Изменили `bot.py` — сохраните, закоммитьте и запушьте снова:
```bash
git add .
git commit -m "Что изменил"
git push amvera master
```
Amvera сама пересоберёт и перезапустит бота.

### Частые ошибки

- **"Terminated by other getupdates request"** — где-то ещё запущена вторая копия бота с тем же токеном (например, вы забыли остановить локальный запуск). Остановите лишний процесс, оставьте только один.
- **Бот не отвечает после деплоя** — проверьте вкладку "Логи" в Amvera: обычно там видно, что `BOT_TOKEN` не задан или задан с опечаткой.
- **Отчёты о топливе пропали после обновления кода** — не задана переменная `DB_PATH=/data/db.sqlite3`, база писалась во временную папку.

## Шаг 4. Включить карту (Mini App)

Карта — это веб-страница внутри Telegram, которая открывается по кнопке. Чтобы её подключить:

1. В Amvera откройте вкладку **«Настройки»** → **«Домены»** → **«Создать доменное имя»**. Выберите бесплатный домен от Amvera (третьего уровня, например `azs-spb-bot.amvera.io`) и подтвердите.
2. У этого домена настройте маршрут: путь `/` → порт `8080` (это порт, который слушает наш веб-сервер — уже прописан в `amvera.yml`).
3. Подождите пару минут, пока выпустится бесплатный SSL-сертификат.
4. В **«Переменные окружения»** добавьте ещё одну переменную:
   - `MAP_URL` = `https://azs-spb-bot.amvera.io/map` (замените на ваш реальный домен из шага 1)
5. Пересоберите проект.
6. В Telegram отправьте боту `/start` — должна появиться кнопка **«🗺 Открыть карту»**. Она откроет карту со всеми 97 станциями, цветными точками по статусу, и позволит тапнуть на станцию и сразу отметить топливо.

Если кнопка не появилась — значит `MAP_URL` не сохранился или пуст (кнопка показывается только когда эта переменная задана).
Если карта открывается, но пустая/белая — скорее всего, домен ещё не привязался или сертификат не выпустился; подождите и обновите.

## Шаг 5. Баллы, звания и еженедельный пост в канал

За каждый отчёт о топливе начисляются баллы (подробные правила — в `strategiya-prodvizheniya.md`, раздел 2). Команды в боте:

- `/профиль` — баллы, звание, стрик, место в топе недели
- `/топ` — топ-10 недели прямо в боте

**Автопост в канал.** Если задана переменная `CHANNEL_ID` (см. Шаг 3), каждый понедельник в 09:00 МСК бот сам публикует топ-10 недели в канал — без вашего участия.

**Расширенный еженедельный пост.** `weekly_report.py` — отдельный скрипт с четырьмя рубриками (статистика недели, топ, разведчики, благодарности за исправление карты). Запускать **на сервере Amvera** (там настоящая база), не локально:

```bash
python3 weekly_report.py            # печатает текст в консоль — скопировать вручную в канал
python3 weekly_report.py --send     # публикует все рубрики прямо в канал
```

⚠️ **Не запускайте оба механизма одновременно в один день** — автопост бота публикует упрощённый топ-10, а `weekly_report.py --send` публикует более полный набор постов, включая тот же топ. Если используете `weekly_report.py --send` по понедельникам вручную (или по cron), либо не задавайте `CHANNEL_ID` боту вообще, либо смиритесь, что топ придёт в канал дважды в разных форматах.

## Что дальше

1. **Распространение.** Дайте ссылку на бота в своём Telegram-канале "4 Тропы и всякая дичь" — это самый быстрый способ набрать первых репортёров. Без критической массы людей краудсорсинг не работает: 5 активных пользователей не покроют 40 станций города.
2. **Второй источник данных (аналитический сигнал).** Когда наберётся база пользователей, можно добавить отдельный необязательный сигнал — например, отслеживание, пропадает ли конкретная АЗС из открытых агрегаторов цен на топливо, с явной пометкой "источник: цены, не подтверждено людьми". Не смешивать с отчётами водителей в одну цифру — это разные по надёжности данные.
3. **Веб-версия синхронизирована.** `azs-spb-monitor.jsx` больше не хранит станции локально — тянет живые данные из `/api/stations` и пишет отчёты через `/api/report` (нужен только домен вашего Amvera-приложения при первом запуске артефакта).
4. **Домен и Mini App.** Если захотите красивый интерфейс с картой внутри Telegram (Telegram Mini App) — это следующий шаг после того, как проверите, что люди вообще пользуются ботом в текстовом виде.

## Ограничение ответственности

Данные вносятся сообществом добровольно и могут быть неточными или устаревшими. Бот не является официальным источником информации о топливе и не связан с сетями АЗС.
